# NCK Replay System

__PYTHON VERSION 3.11 RECOMMENDED!!__
\n
**NRS - NCK Replay System**

A lightweight, timestamp-based macro recording and replay system written in Python.

NRS records keyboard and mouse input and converts it into a custom `.rep` replay format that can later be interpreted and executed by the NRS runtime.

## Features

* 🎯 Precise mouse movement recording
* 🖱️ Mouse clicks
* ⌨️ Keyboard input
* 🔤 Text typing
* 🔗 Keyboard combinations such as `CTRL+A`
* 🖱️ Mouse dragging
* ⏱️ Timestamp-based execution
* 📄 Human-readable `.rep` files
* 💻 Command-line interface
* ⚡ Event-queue based recording architecture
* 🧩 Custom macro OpCode system

## How NRS Works

NRS is split into two main components:

```text
Record.py
    │
    │ Keyboard / Mouse events
    ▼
Event Queue
    │
    ▼
OpCode Compiler
    │
    ▼
.rep Replay File
    │
    ▼
Execute.py
    │
    ▼
Keyboard / Mouse Output
```

The recorder captures raw input events and converts them into NRS OpCodes.

The executor reads those OpCodes and reproduces the recorded actions.

## Manual Scripting

There's a helper script for manual .rep scripting called `Positioner.py`.
It will constantly print out your cursors position.

## Recording

Start the recorder with:

```bash
python Record.py -f Replays/Recorded.rep -b Escape
```

Arguments:

| Argument | Description                |
| -------- | -------------------------- |
| `-f`     | Output `.rep` file         |
| `-b`     | Key used to stop recording |

Example:

```bash
python Record.py -f Replays/Test.rep -b Escape
```

After starting the recorder, perform the actions you want to capture.

Press the configured stop key when finished.

## Replaying

Run the executor:

```bash
python Execute.py -f Replays/Test.rep
```

The executor reads the replay file and executes each OpCode according to its timestamp.

## `.rep` Format

`.rep` files are the native replay format of NRS.

Example:

```text
# .rep Macro File
# Generated by Nick's .rep recorder
MOV 0.1523 549 1188 0.0121
CLICK 0.8432 LEFT
KEY 1.2041 F2
TYPE 1.4217 hello
KEY 2.1034 ENTER
```

The first value after an OpCode is its timestamp.

For example:

```text
CLICK 1.50 LEFT
```

means:

> Execute a left mouse click at 1.50 seconds into the replay.

## OpCodes

NRS currently supports several core OpCodes.

### MOV

Moves the mouse.

```text
MOV <timestamp> <x> <y> <duration>
```

Example:

```text
MOV 0.2500 800 450 0.0150
```

### CLICK

Clicks a mouse button.

```text
CLICK <timestamp> <button>
```

Example:

```text
CLICK 1.2500 LEFT
```

Supported buttons depend on the mouse backend.

### KEY

Presses a keyboard key or key combination.

```text
KEY <timestamp> <key>
```

Examples:

```text
KEY 2.1000 F2
KEY 2.3000 CTRL+A
KEY 2.5000 ENTER
```

### TYPE

Types text.

```text
TYPE <timestamp> <text>
```

Example:

```text
TYPE 3.0000 Hello world
```

### DRAG

Represents a mouse drag.

```text
DRAG <timestamp> <x1> <y1> <x2> <y2> <duration>
```

Example:

```text
DRAG 4.0000 400 300 900 600 1.25
```
